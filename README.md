# Student Academic Data Preprocessing and Exploratory Analysis

## Project Overview

This project demonstrates a basic data preprocessing and exploratory
data analysis workflow using Python.

## Objectives

- Inspect and understand a student dataset
- Identify and handle missing values
- Detect and remove duplicate records
- Encode categorical variables
- Select relevant features
- Scale numerical features
- Perform exploratory data analysis

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Preprocessing Steps

1. Dataset inspection
2. Missing value handling
3. Duplicate removal
4. Categorical encoding
5. Feature selection
6. Numerical feature scaling
7. Exploratory data analysis

## EDA Performed

- Exam score distribution
- Attendance distribution
- Attendance vs. exam score relationship
- Correlation analysis
- Program-wise exam score comparison

## Final Result

The cleaned dataset contains 5 student records and 10 columns,
with no missing values or duplicate records.
